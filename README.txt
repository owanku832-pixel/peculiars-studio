PECULIAR'S STUDIO WEBSITE

FILES
- index.html: website content
- styles.css: website design
- script.js: menu and enquiry form behavior

TO PREVIEW
Double-click index.html to open it in your browser.

BEFORE USING THE ENQUIRY FORM
Open script.js in a text editor and replace ADD_YOUR_EMAIL_HERE with the email address where you want to receive enquiries.

PUBLISHING WITH GITHUB PAGES
1. Create a public GitHub repository named peculiars-studio.
2. Upload these four files to the repository root (not inside another folder).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub to publish the site.

The enquiry form is a simple email-app demo. It does not store enquiries on the website.
